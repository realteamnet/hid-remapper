CLAUDE- rename modules to rgb-led and vdisk, board LEDs, upstream sync

- firmware/rp2040-ws2812 -> firmware/rgb-led,
  firmware/rp2040-vdisk -> firmware/vdisk. CLAUDE.md is no longer kept
  in the repo.
- rgb-led settings are now 0xWWLOOOPP: PP = FF uses the board's
  PICO_DEFAULT_WS2812_PIN (feather_host, waveshare_rp2350_usb_a), and
  WW = 0x80 | n drives GPIO n high while the LED is in use (LED power
  enable). The PIO-USB VBUS-enable pin is never used. Old settings
  values behave as before.
- CI: compile checks for feather_host and waveshare_rp2350_usb_a.
- sync-upstream.yml: daily merge of jfedor2/hid-remapper master, then
  a build; a conflict fails the run and pushes nothing.
  build-rp2040.yml takes an optional `ref` input for that.
- vdisk: the build stops if the config version or the number of
  expression ops changes upstream.
