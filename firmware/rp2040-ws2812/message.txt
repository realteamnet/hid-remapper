CLAUDE- ws2812: 0xBBRRGGBB colour register (brightness byte); layer colour example

Register 32 is now read as 0xBBRRGGBB: BB = brightness (00 = default
WS2812_BRIGHTNESS), so expressions can set colour and brightness per layer.
Example config: Scroll Lock mapped to Register 2 (key chosen in the UI),
expression 1 cycles layers 0-3, expressions 2-4 drive Layer 1-3 mappings,
expression 5 picks the colour per active layer (layer_state + ifte).
No hid-remapper code changes.
