CLAUDE- ws2812: name colour format 0xIIRRGGBB (II = intensity)

"BB" for brightness was ambiguous with the blue channel. Rename to
0xIIRRGGBB and WS2812_BRIGHTNESS -> WS2812_DEFAULT_INTENSITY in code,
docs and the example config comments. No behaviour change.
