CLAUDE- ws2812: master brightness nibble in settings register 31

Register 31 is now 0x00LOOOPP: L = master brightness 1 (dimmest) .. F
(full), 0 = full (existing values unchanged). Levels from a ~x1.35/step
table, multiplied with each colour's II and rounded up so a lit colour
never goes dark. Docs updated.
