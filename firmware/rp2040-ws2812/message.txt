CLAUDE- ws2812: runtime LED GPIO and colour order via register 31

Register 31 = 0x000OOOPP: PP = data GPIO, OOO = colour order nibbles
(1=R 2=G 3=B, e.g. 123 = RGB, 213 = GRB); 0 = build defaults. Applied when
it changes: moving pins turns the old LED off, drains the FIFO, returns the
old pin to an input and re-inits the SM on the new pin. PIO-USB pins and
invalid orders are refused. WS2812_RGB_ORDER (0/1) is replaced by
WS2812_COLOR_ORDER (same nibble encoding; CMake default 0x123).
