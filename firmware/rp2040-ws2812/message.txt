CLAUDE- ws2812: default to RGB colour order for the RP2040-Zero clone

Hardware test of the PoC remapper.uf2 showed the power-on red->green->blue
sweep as green->red->blue, so this board's LED takes R,G,B byte order.
ws2812.cmake now defaults WS2812_RGB_ORDER=1 for both remapper and
ws2812_test (C default stays 0 = standard GRB). Docs updated.
