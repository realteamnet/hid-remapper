CLAUDE- vdisk: fixed-size LOG.TXT, no remounts for log lines

LOG.TXT always has 4096 bytes (newest lines, blank-padded), so its
directory entry never changes and an uncached read sees new lines.
The drive no longer remounts for the log, which opened an Explorer
window every time. It remounts only when a config is applied.
