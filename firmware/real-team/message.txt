CLAUDE-RGB demo: Calc key cycles the layers

The demo layer key is now Calc (consumer 0x000C0192, e.g. the 8BitDo numpad)
instead of Scroll Lock: 7 sticky Calc -> Layer k+1 mappings, plus Calc ->
Nothing on layer 7, so Calc never reaches the computer (it would open the
calculator). README and the config.html example text updated.
